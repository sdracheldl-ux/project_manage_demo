# 企业线索洞察 — 需求设计文档（PRD）

> 版本：v1.0
> 日期：2026-10-28
> 模块归属：产业情报 → 企业线索洞察
> 数据来源：外部数商企业数据采买（DEMO 阶段全 mock）
> 参考项目：链长招商管服平台 — 企业画像页（仅参考布局/交互，剔除其自有评分/AI 报告/政策匹配等衍生功能）

---

## 一、需求背景与目标

### 1.1 背景
为补齐 SOW 中"项目线索挖掘、研判与预警"能力，依托外部数商采买的企业全量数据，向招商人员提供基于企业名称关键词查询的统一企业信息查询入口，集中呈现目标企业的工商、对外投资、经营、风险、司法、知识产权、历史变更、董监高、年报、上市、关系图谱等全维度信息，辅助招商线索研判。

### 1.2 范围边界
- **纳入**：企业搜索、企业详情页信息展示、关系图谱占位。
- **不纳入**（本次不做，页面也不体现）：
  - 5 维度能力评分（综合/创新/成长/投资/投资信号）
  - AI 招商可行性分析报告
  - 政策匹配
  - 同行推荐
  - 产业链修正 / 历史修正 / 加入名单 / 下载报告等衍生操作
- **预警**：项目进展预警不在本模块，已由现有 DEMO 覆盖。

## 二、菜单与路由

### 2.1 菜单
在左侧主导航 **统计看板 下方** 新增一级菜单「**产业情报**」（图标：`RadarOutlined`）：

```
产业情报
└─ 企业线索洞察   路由：/intelligence/enterprise
```

### 2.2 路由
| 路径 | 组件 | 说明 |
|---|---|---|
| `/intelligence/enterprise` | `EnterpriseSearch` | 企业搜索页 |
| `/intelligence/enterprise/detail/:name` | `EnterpriseDetail` | 企业详情页（`name` 为 URL 编码企业全称） |

- `/intelligence/enterprise` → `['产业情报', '企业线索洞察']`
- `/intelligence/enterprise/detail` → `['产业情报', '企业线索洞察', '企业详情']`

### 2.4 权限
DEMO 阶段全视角（投促局/园区/国企）均可访问，不做数据范围区分。

## 三、企业搜索页（EnterpriseSearch）

### 3.1 布局
沿用现有 `page-container` + `table-card` 容器风格（与项目列表页一致）。

```
┌──────────────────────────────────────────────┐
│ 面包屑：产业情报 / 企业线索洞察              │
├──────────────────────────────────────────────┤
│ table-card                                   │
│  ┌────────────────────────────────────┐      │
│  │ [企业名称关键词] [行业▼] [地区▼]   │      │
│  │              [查询] [重置]          │      │
│  └────────────────────────────────────┘      │
│  ┌────────────────────────────────────┐      │
│  │ 序号 企业名称  统一信用代码 法定代表人│      │
│  │      注册资本  成立日期 登记状态 操作 │      │
│  │ 1    ...                          │      │
│  │ 2    ...                          │      │
│  └────────────────────────────────────┘      │
└──────────────────────────────────────────────┘
```

### 3.2 筛选项
| 筛选项 | 类型 | 是否必填 |
|---|---|---|
| 企业名称关键词 | 输入框（模糊匹配） | 否（空时返回全部） |
| 行业 | 下拉（国标行业一级分类） | 否 |
| 地区 | 下拉（省/直辖市） | 否 |

### 3.3 列表表格
- 序号列固定左侧（55px，居中，dataIndex `index`）— 沿用项目硬约束。
- 操作列 `action-col-cell`，右内边距 16px；操作列仅一个按钮「详情」。
- 表格 `tableLayout="fixed"`，`scroll.x` = 各列宽度之和。

| 列 | dataIndex | 宽度 | 对齐 |
|---|---|---|---|
| 序号 | index | 55 | center |
| 企业名称 | name | 280 | left |
| 统一社会信用代码 | creditCode | 180 | left |
| 法定代表人 | legalRep | 120 | center |
| 注册资本 | regCapital | 160 | right |
| 成立日期 | foundDate | 120 | center |
| 登记状态 | status | 120 | center |
| 操作 | - | 100 | center |

登记状态用 Tag：
- 在营（开业）企业 → `color="success"`
- 注销 / 吊销 / 停业 → `color="default"`
- 其他 → `color="warning"`

### 3.4 交互
- 点击「查询」：根据条件过滤 mock 列表。
- 点击「重置」：清空筛选项。
- 点击行内「详情」：跳转 `/intelligence/enterprise/detail/:name`。
- 分页：沿用现有 DEMO 分页器（每页 10 条）。

### 3.5 空状态
无搜索结果时显示 Empty 组件，文案「未查询到符合条件的企业」。

### 4.2 顶部企业概要卡片

**头部行**：
- 左：企业 Logo（48×48 圆角占位图）+ 企业名称（H3 加粗）+ 登记状态 Tag
- 右：所属集团 Tag（蓝色边框）+ 行业 Tag

**Descriptions 字段（4 列 × 3 行）**：
| 列1 | 列2 | 列3 | 列4 |
|---|---|---|---|
| 统一社会信用代码 | 法定代表人 | 注册资本 | 成立日期 |
| 企业类型 | 国标行业 | 经营期限自 | 核准日期 |

- 不放能力评分、不放统计指标行（招投标/榜单/对外投资/创新产出计数）、不放操作按钮（修正/加入名单/下载报告）。

### 4.4 右侧内容区通用规则

- 每个区块以 `sectionTitleStyle`（4px 蓝色左竖线 + 加粗深色标题）作为分类标题。
- 区块顶部显示统计行：`共 X 条记录`（X=0 时显示空状态文案 `大数据暂未监测到相关数据`，与参考项目一致）。
- 表格统一使用 antd Table，`size="small"`，`tableLayout="fixed"`，`scroll.x` 匹配列宽之和。
- 表格行无点击弹窗（参考项目仅有 2 处行内链接：法院公告/招聘信息，本次也保留「详情」链接形式）。
- **分页：采用「点击加载更多」无限滚动**（沿参考项目交互，不使用页码）。
  - 实现：表格底部追加一行「点击加载更多」按钮，点击后追加下一页数据到当前列表。
  - 每页 10 条，mock 数据每区块准备 10-30 条不等。
- 空状态：`<Empty description="大数据暂未监测到相关数据" />`，灰色文案。
- 筛选/标签切换：参考项目股东区块有「当前股东 / 历史股东」切换，对外投资有筛选项，本次对应区块保留一致交互。

### 4.5 各区块字段清单

> 以下字段均来自外采数据范围。DEMO 阶段所有数据用 mock，字段以参考项目展示形式为准。

#### 4.5.1 工商信息

**工商登记**
- 展示形式：Descriptions（4 列卡片）
- 字段：企业名称、统一社会信用代码、登记状态、法定代表人、注册资本、实缴资本、组织机构代码、成立日期、核准日期、登记机关、所属产业、企业类型、国标行业、产业领域、英文名称、开户银行、开户账号、经营期限自、纳税人资质、参保人数、经营范围、企业简介

**股东及出资**
- 头部切换：当前股东 / 历史股东
- 表格列：股东名称 | 股东类型 | 认缴出资额(万元) | 出资比例 | 出资日期
- 统计行：`共 X 位股东`（区分自然人/非自然人）

**主要管理人员**
- 展示形式：按角色分组列表（董事会成员 / 监事会成员 / 高管人员 / 其他人员）
- 字段：姓名 + 职务

**分支机构**
- 表格列：分支机构名称 | 负责人 | 注册资本 | 成立日期 | 登记状态

**集团信息**
- 表格列：集团名称 | 母公司 | 集团成员数 | 注册资本 | 成立日期
- 详情：点击行展开集团成员列表

**变更信息**
- 筛选标签：全部 / 高管变更 / 股东变更 / 注册资本变更 / 经营范围变更 / 地址变更
- 表格列：变更事项 | 变更前内容 | 变更后内容 | 变更日期

#### 4.5.2 对外投资

**企业对外投资**
- 特征标签（参考项目）：投资次数偏多 / 覆盖度广 / 一年/三年/五年内有对外投资
- 筛选器：出资比例（6 档）/ 登记状态（3 项）/ 投资日期（按年）
- 表格列：被投企业名称 | 注册资本(万元) | 出资金额(万元) | 出资比例 | 登记状态 | 投资日期

**历史退出对外投资**
- 表格列：被投企业名称 | 进入时间 | 退出时间 | 持股时长 | 登记状态 | 成立日期

**控制企业**
- 表格列：控制企业名称 | 经营状态 | 成立日期 | 所属地区 | 注册资本(万元)

#### 4.5.3 经营信息

### 6.2 通用组件说明

**SectionWrapper**：所有区块的标准外壳
- props：`title`、`count`、`extra`（筛选/标签切换）、`children`
- 行为：渲染 `sectionTitleStyle` 标题 + 统计行 + children，空数据自动渲染 Empty。

**LoadMoreTable**：封装「点击加载更多」交互
- props：`columns`、`dataSource`（全量）、`pageSize=10`
- 行为：内部维护 `visibleCount`，初始展示前 10 条；底部按钮点击后追加 10 条；加载完所有数据后按钮消失。

**AnchorNav**：左侧锚点导航
- props：`menuConfig`、`activeKey`、`onSelect`
- 行为：一级分组可折叠；二级菜单点击触发 `onSelect(key)`；当前激活项高亮蓝色背景。

### 6.3 样式约定
- 颜色：使用 `COLORS` 常量，主色 `#1677ff`。
- 卡片：`page-container` + `table-card` + `pageCardStyle`。
- 分类标题：`sectionTitleStyle`（4px 蓝色左竖线）。
- 详情页头部：`detailHeaderStyle` + `detailHeaderLeftStyle`，返回按钮 `type="text"` 文字「返回」`marginLeft: -8`。
- Descriptions：沿用 `descriptionsProps`（4 列、bordered、label 宽 140）。
- 表格：`tableLayout="fixed"`，`scroll.x` = 列宽之和，操作列 class `action-col-cell`，序号列 55px 居中。

## 七、交互细节汇总

| 场景 | 交互 |
|---|---|
| 搜索页查询 | 输入关键词 → 点击「查询」过滤列表 |
| 搜索页重置 | 清空筛选项，恢复全量 mock |
| 搜索页跳详情 | 点击行内「详情」→ 跳转详情页 |
| 详情页返回 | 顶部返回按钮 → 回到搜索页（保留筛选状态） |
| 左侧导航点击 | 二级菜单点击 → 右侧滚动定位 + 高亮当前 |
| 左侧导航折叠 | 一级分组点击 → 折叠/展开子菜单 |
| 表格加载更多 | 底部按钮点击 → 追加 10 条，加载完隐藏按钮 |
| 股东切换 | 当前股东 / 历史股东 切换 → 表格数据切换 |
| 对外投资筛选 | 出资比例 / 登记状态 / 投资日期 联合筛选 |
| 变更信息筛选 | 标签筛选（全部 / 高管变更 / 股东变更 ...） |
| 客户供应商切换 | 客户 / 供应商 标签切换 |
| 法院公告详情 | 行内「详情」链接 → 弹窗展示完整公告内容 |
| 招聘信息详情 | 行内「查看详情」链接 → 弹窗展示完整职位描述 |
| 年报年份切换 | 年份下拉切换 → 全部子区块数据刷新 |
| 空状态 | Empty 组件 + 文案「大数据暂未监测到相关数据」 |
