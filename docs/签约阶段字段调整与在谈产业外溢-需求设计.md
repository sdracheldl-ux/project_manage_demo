## 2. 需求二：签约阶段字段调整

### 2.1 保留字段集（弹窗口径，共 32 个）

**A. 在谈带出（19 个，与在谈同键同控件，转签约时自动回显可改）**：
项目名称、内外资、来源地、产业类别、行业类别、次要行业类别、项目简介、计划投资总额(亿元)、责任单位、项目分类、需投资金额(亿元)（投资类时出现）、投资主体、对接时间、企业类别、是否为存量企业、注册资本(亿元)、是否飞地园区、**是否产业外溢（新增）**、楚商类型

**B. 签约特有（13 项）**：

| # | 字段 | 口径变化 |
|---|------|---------|
| 1 | 建设性质 | 保留现有两级结构（一级必填 + 二级） |
| 2 | 招商类型 | 必填 |
| 3 | 招商类型说明 | **必填 → 非必填**（≤100 字） |
| 4 | 是否浙商 | 必填；**去掉**浙商类型、浙商基本信息联动 |
| 5 | 用地情况 | 必填 |
| 6 | 是否总部经济 | 必填；是 → 总部经济类型两级改为**选填** |
| 7 | 备案证金额(亿元) | 必填，数字 |
| 8 | 固投金额(亿元) | 必填，数字 |
| 9 | 协议签订时间 | 必填，日期 |
| 10 | 协议类型 | 必填（投资协议/框架协议/补充协议） |
| 11 | 协议凭证附件 | 选填上传 |
| 12 | 是否注册 | 必填；是 → 联动**仅保留**注册时间*、注册资本(金额+单位)*、注册公司名称*；**去掉**社会信用代码、工商注册凭证 |
| 13 | 签约主体 | 必填，单行文本 |

### 2.2 移除字段（市级冗余，约 40 项）

纳统项目名称/编码、策划类型、立项属性、项目区域、建设地址、是否FDI/FDI金额/内外贸、965产业链/次要产业链、五谷集群、所属片区、用地/办公面积、是否研发中心、是否重点产业/重点产业类型、是否推送省库、国家级行业分类(GB)、投资形态、预计年产值/年税收、当年/现阶段到资、到位资金用途说明、**年度计划投资安排(表格)**、是否战略性新兴产业、是否先进制造业/服务业类别、签约主体信用代码、企业性质、企业类别佐证、投资主体社会信用代码、投资主体联系人/电话、区/市投促局联系人及电话、其它凭证、工商注册凭证、报送规范分类、到资金额、备注、楚商基本信息、申报理由、预计产值、省市联动等。

### 2.3 页面改造

| 文件 | 改动 |
|------|------|
| `ZhuanQianyueModal.jsx` | **重写**（现 1000+ 行 → 精简）：在谈 19 字段带出回显可改 + 签约 13 项待填；移除 GB 分类/年度计划表/四级责任人等全部冗余 |

### 2.4 不动项

## 3. 实施顺序

1. 需求一：在谈 4 文件加「是否产业外溢」
2. 需求二：ZhuanQianyueModal 重写 → QianyueEditModal 重构 → QianyueDetail 重建 → Qianyue 列表列/筛选
3. `npm run build` + 本地预览回归

## 4. 验收要点

1. 在谈新增/编辑/转在谈弹窗均有必填「是否产业外溢」；详情/列表/筛选可见可用；
2. 转签约弹窗仅剩 32 字段：在谈 19 项自动带出，签约 13 项待填；招商类型说明、总部经济类型（选中"是"后）、非必填可跳过；
3. 是否注册=是 → 仅出现注册时间/注册资本/注册公司名称三个联动项且必填；=否 → 全部隐藏且可提交；
4. 是否浙商=是 → 不再出现浙商类型/基本信息；
5. 签约列表列/筛选精简生效，企业性质筛选消失；
6. 签约详情字段集与弹窗一致，项目简介通栏置底；
7. 转落地、导入、分派、进展、移交回归正常；build 通过无控制台错误。
